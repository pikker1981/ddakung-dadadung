따쿵따다둥 · 저장과 개인정보

곡과 설정, 연습 기록은 현재 기기·브라우저의 localStorage에 저장됩니다. PC와 iPad 사이에 자동 동기화되지 않습니다. 브라우저 데이터를 지우거나 저장 공간이 부족하면 사라질 수 있으니, 중요한 곡은 저장 메뉴의 .ddakung.json 파일 또는 곡 목록의 전체 백업으로 보관하세요.

이 프로젝트는 원본 사이트의 분석 스크립트, 피드백 전송 및 앱스토어 홍보를 실행하지 않습니다. 악보 편집·재생·파일 출력은 브라우저 안에서 처리합니다. 외부 링크를 직접 누르면 해당 사이트가 열립니다. Vercel 같은 호스팅 서비스의 기본 요청 로그는 호스팅 사업자의 정책을 따릅니다.

PC 전용 이미지 악보 인식에서 ‘인식 시작’을 누르면 선택한 이미지 영역이 로컬 Codex CLI를 통해 로그인된 계정의 온라인 모델로 전송됩니다. 별도 API 키는 쓰지 않지만 인터넷과 계정 사용량이 필요합니다. 로컬 임시 이미지와 인식 결과는 작업 완료·실패·취소 후 삭제합니다. 강제 종료 시에는 PC의 이미지 인식 임시 폴더에 남을 수 있습니다. 인식 결과는 사용자가 확인한 뒤에만 새 곡으로 저장됩니다.

배포 URL이 달라지면 별도의 저장 공간으로 취급됩니다. 미리보기에서 만든 곡은 파일로 내보낸 뒤 실제 배포 주소에서 다시 여세요. 홈 화면 설치 기능은 제공하지만 서비스 워커와 완전 오프라인 캐시는 구현하지 않았습니다.
