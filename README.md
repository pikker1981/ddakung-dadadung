# 따쿵따다둥 · iPad

개인용 비공개 드럼 악보 작업실. 이 저장소와 배포는 비공개 개인 접근 전용입니다.

- 가로: 악보/입력 나란히, 세로: 악보/입력 탭
- 설정 → 드럼 믹서: 전체 화면 12채널 믹서와 개별 튜닝
- 마디/박 선택 버튼, 복사/붙여넣기/되돌리기, 20마디 페이지
- 선택된 모델의 강약·주법·반복 타격 샘플만 포함
- 악보는 브라우저에 저장되며 JSON 파일로 PC와 이동합니다. 자동 기기 동기화는 없습니다.
- 첫 실행 시 터치로 오디오를 활성화하세요. PC CLI 이미지 인식은 포함하지 않습니다.

`npm ci`, `npm run dev`, `npm test`, `npm run build`.

Vercel 프로젝트의 Vercel Authentication을 **All Deployments**로 설정한 후 배포해야 합니다. 샘플 원음은 개인 사용 범위이며 공개 재배포할 수 없습니다. 샘플/폰트 출처는 각 manifest와 notices에 포함합니다.
